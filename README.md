# Landing Page - Processo Seletivo

Este projeto foi desenvolvido como parte do desafio técnico para a vaga de Estágio Tech na EMBRAER. O objetivo era se apresentar de maneira criativa e sucinta. Para isso, desenvolvi uma interface simples porém moderna, responsiva e funcional utilizando tecnologias web.

### 🛠️ Tecnologias Utilizadas
<b>HTML5</b>: Estruturação semântica do conteúdo.

<b>CSS3</b>: Estilização, Flexbox e Grid para layout.

<b>JavaScript</b>: Comportamentos interativos.

<b>Google Fonts</b>: Tipografia personalizada.
